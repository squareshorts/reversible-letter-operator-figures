# Privacy and data-access statement

This public repository contains no names, dates of birth, raw PsychoPy records, direct identifiers, or participant-level analysis rows.

The study cohort consists of children. The original consent and ethics framework did not authorize unrestricted public release of participant-level data. For that reason, the public archive contains only non-identifying aggregate outputs, analysis code that can be run against the restricted analysis table, figure-generation code, tests, and documentation.

The participant-level analysis table is retained under institutional control. A deidentified copy may be made available for legitimate scientific verification subject to ethics approval, institutional authorization, and an appropriate data-use agreement. The restricted table uses coded participant identifiers and anonymized school labels.

The public schema is documented in `docs/restricted_data_schema.md` so that the statistical analysis can be inspected without exposing protected records.
